The engine performs probabilistic risk assessment across 6 shadow trading portfolios, generating Value-at-Risk (VaR), Conditional VaR (CVaR), and portfolio stress scenarios with sub-100ms latency requirements. Built on TypeScript/Node.js with GPU acceleration via WebGL, the implementation enforces mathematical precision, numerical stability, and seamless integration with existing multi-regime trading infrastructure.

**Key Objectives:**
- Generate 100,000+ correlated price paths in <1s (CPU) or <100ms (GPU)
- Compute VaR/CVaR at 95% and 99% confidence levels with Kupiec backtesting
- Maintain positive semi-definite correlation matrices under stress scenarios
- Achieve zero look-ahead bias and full reproducibility via deterministic seeding

### Day 6: Stochastic Path Generation

**Component 1: Geometric Brownian Motion (GBM) Core**

**1. Implementation Specifications**
- **Class Hierarchy:**
  ```typescript
  abstract class StochasticProcess {
    abstract nextState(state: StateVector, dt: number): StateVector;
    abstract validatePath(path: PathMatrix): boolean;
  }
  
  class GeometricBrownianMotion extends StochasticProcess {
    private mu: number;        // Drift coefficient [scalar]
    private sigma: number;     // Volatility coefficient [scalar]
    private seed: number;      // PCG64DXSM seed [uint32]
    
    constructor(params: GBMParams) { ... }
    
    // Vectorized path generation
    generatePaths(
      S0: number,              // Initial price [scalar]
      T: number,               // Time horizon [years]
      N: number,               // Timesteps [integer]
      M: number                // Number of paths [integer]
    ): PathTensor;             // Output: [M, N+1] Float64Array
  }
  ```
- **Mathematical Formulation:**
  - SDE: `dS_t = μS_t·dt + σS_t·dW_t` where `W_t ~ N(0, t)`
  - Closed-form solution: `S_t = S_0 · exp((μ - σ²/2)t + σW_t)`
  - Discretization (Euler-Maruyama): `S_{t+Δt} = S_t · exp((μ - σ²/2)Δt + σ√Δt·Z)` where `Z ~ N(0,1)`
- **Tensor Dimensionalities:**
  - Input: `S0 ∈ ℝ¹`, `T ∈ ℝ¹`, `N ∈ ℕ`, `M ∈ ℕ`
  - Output: `paths ∈ ℝ^{M×(N+1)}` (row-major, Float64Array)
  - Intermediate: `dW ∈ ℝ^{M×N}` (standard normal increments)

**2. Algorithmic Nuances & Numerical Stability**
- **Floating-Point Drift Management:**
  - Use compensated summation (Kahan-Babuška) for cumulative returns
  - Enforce `S_t ≥ ε` where `ε = 1e-8` to prevent log(0) in subsequent calculations
  - Pre-compute `(μ - σ²/2)` once per path batch to reduce rounding error
- **Random Number Generation:**
  - PCG64DXSM algorithm for high-quality parallel streams
  - Mode-specific seeds: `seed = baseSeed XOR modeId` for reproducibility
  - Skip-ahead capability: `2^128` steps for independent path blocks
- **Vectorization Strategy:**
  - Box-Muller transform for batch normal variates: `Z = √(-2lnU₁)·cos(2πU₂)` where `U₁,U₂ ~ Uniform(0,1)`
  - SIMD-friendly layout: Array-of-Structures → Structure-of-Arrays (SoA)
  - Memory alignment: 64-byte boundaries for AVX2 operations

**3. Hardware & Performance Orchestration**
- **CPU/GPU Dispatch Logic:**
  ```typescript
  class PathGenerator {
    private useGPU: boolean;
    private gpuKernel: gpu.Kernel | null;
    
    constructor(config: Config) {
      this.useGPU = this.detectWebGL();
      if (this.useGPU) {
        this.gpuKernel = this.compileGPUKernel();
      }
    }
    
    generate(M: number, N: number): Float64Array {
      if (this.useGPU && M >= 1000) {
        return this.generateGPU(M, N);  // WebGL compute shader
      } else {
        return this.generateCPU(M, N);  // NumJS vectorized
      }
    }
  }
  ```
- **Numba-Style Optimization (TypeScript equivalent):**
  - Use `numjs` for vectorized operations: `nj.exp()`, `nj.multiply()`, `nj.add()`
  - Parallel loop simulation: `for (let i = 0; i < M; i++)` → `nj.arange(M).forEach()`
  - Memory pooling: Reuse `Float64Array` buffers to prevent GC pressure
  - Batch size tuning: Process paths in chunks of 1024 for L1 cache efficiency
- **SIMD Data Layout:**
  - Interleaved storage: `[path0_t0, path1_t0, ..., pathM_t0, path0_t1, ...]`
  - Enables SIMD horizontal operations on same timestep across paths

**4. Rigorous Testing & Validation Protocol**
- **Distribution Fidelity (Kolmogorov-Smirnov Test):**
  ```typescript
  function validateGBM(paths: PathTensor, params: GBMParams): boolean {
    const logReturns = computeLogReturns(paths);
    const empiricalCDF = estimateCDF(logReturns);
    const theoreticalCDF = normalCDF(params.mu, params.sigma);
    const KS = sup|F_n(x) - F(x)|;
    return KS < criticalValue(0.05, paths.length);

  ```
- **Martingale Property Check:**
  - Verify `E[S_t / S_0] = exp(μt)` within 1% tolerance
  - Test across multiple seeds: `|sampleMean - theoreticalMean| / theoreticalMean < 0.01`
- **Boundary Condition Tests:**
  - `σ = 0`: Paths should be deterministic exponential growth
  - `μ = 0`: Expected value should remain at `S_0`
  - `T → 0`: Paths should converge to `S_0`

### Day 7: Correlation & Cholesky Decomposition

**Component 2: Correlation Matrix Engine**

**1. Implementation Specifications**
- **Class Hierarchy:**
  ```typescript
  class CorrelationMatrix {
    private covMatrix: ml.Matrix;      // Covariance matrix [nAssets × nAssets]
    private cholFactor: ml.Matrix;     // Cholesky factor L [lower triangular]
    private eigenvals: number[];       // Eigenvalues for validation
    
    constructor(returns: number[][]);  // Input: [nTimesteps × nAssets]
    
    decompose(): DecompositionResult;  // Returns L where Σ = LL^T
    stressTest(scenario: StressScenario): CorrelationMatrix;
    isPositiveDefinite(tol: number): boolean;
  }
  ```
- **Mathematical Formulation:**
  - Covariance: `Σ = (1/(n-1)) · X^T · X` where `X` is demeaned returns
  - Cholesky: `Σ = L · L^T` where `L` is lower triangular
  - Eigenvalue check: `λ_min(Σ) > 0` for positive definiteness
- **Tensor Dimensionalities:**
  - Input returns: `X ∈ ℝ^{T×A}` (T timesteps, A assets)
  - Covariance: `Σ ∈ ℝ^{A×A}` (symmetric, positive semi-definite)
  - Cholesky factor: `L ∈ ℝ^{A×A}` (lower triangular)

**2. Algorithmic Nuances & Numerical Stability**
- **Positive Semi-Definiteness Enforcement:**
  - **Ledoit-Wolf Shrinkage:**
    ```
    Σ_shrink = δ · F + (1 - δ) · Σ_sample
    ```
    where `F` is constant correlation target, `δ` is shrinkage intensity
  - **Eigenvalue Clipping:**
    ```typescript
    const minEigenval = 1e-8;
    const clippedEigs = eigenvals.map(λ => Math.max(λ, minEigenval));
    Σ_corrected = Q · diag(clippedEigs) · Q^T;
    ```
  - **Modified Cholesky (Gill-Murray):**
    Add diagonal perturbation `E` where `E = diag(τ·max(Σ_ii))` if pivot too small
- **Correlation Breakdown Handling:**
  - Crisis mode: `ρ_ij' = min(ρ_ij × 1.5, 0.99)` (correlation amplification)
  - Flight-to-quality: `ρ_ij' = 0.95` for all `i≠j` (diversification failure)
  - Regime shift: Replace with bear-market correlation matrix
- **Numerical Precision:**
  - Use double precision (Float64) throughout
  - Avoid catastrophic cancellation in `Σ_ij = cov(i,j) / (σ_i · σ_j)`
  - Scale returns to zero mean, unit variance before correlation computation

**3. Hardware & Performance Orchestration**
- **GPU Acceleration (ml-matrix):**
  ```typescript
  import { Matrix } from 'ml-matrix';
  
  class GPUAcceleratedCorrelation {
    computeCovariance(returns: number[][]): Matrix {
      const X = new Matrix(returns);           // GPU memory allocation
      const X_centered = X.subRowVector(mean); // GPU operation
      const cov = X_centered.transpose().mmul(X_centered); // GPU matmul
      return cov.div(returns.length - 1);
    }
    
    choleskyGPU(cov: Matrix): Matrix {
      return cov.cholesky();  // Uses LAPACK/BLAS under the hood
    }
  }
  ```
- **Vectorization Strategy:**
  - Batch covariance computation: Process all asset pairs simultaneously
  - Use `ml-matrix`'s optimized `mmul()` (matrix multiplication)
  - Memory layout: Column-major for BLAS compatibility
- **Parallel Decomposition:**
  - For multiple correlation matrices (6 modes × multiple scenarios)
  - Use `Promise.all()` for independent decompositions
  - Limit concurrency to avoid GPU memory exhaustion

**4. Rigorous Testing & Validation Protocol**
- **Spectral Analysis (Eigenvalue Checks):**
  ```typescript
  function validateCorrelation(C: Matrix): ValidationResult {
    const eigs = C.eigenvalueDecomposition().realEigenvalues;
    const minEig = Math.min(...eigs);
    const condNumber = Math.max(...eigs) / minEig;
    
    return {
      isPositiveDefinite: minEig > 1e-8,
      conditionNumber: condNumber,
      isWellConditioned: condNumber < 1e6,
      symmetryError: max|C - C^T| / max|C|
    };
  }
  ```
- **Cholesky Reconstruction Test:**
  - Verify `||Σ - L·L^T||_F / ||Σ||_F < 1e-10`
  - Test with random positive definite matrices
- **Stress Scenario Validation:**
  - Ensure stressed matrix remains positive definite
  - Check correlation bounds: `-1 ≤ ρ_ij ≤ 1`
- **Monte Carlo Consistency:**
  - Generate paths with correlation matrix
  - Compute empirical correlation from paths
  - Verify `||ρ_empirical - ρ_target||_∞ < 0.01`

### Day 8: VaR & CVaR Implementation

**Component 3: Risk Metrics Calculator**

**1. Implementation Specifications**
- **Class Hierarchy:**
  ```typescript
  abstract class RiskMetric {

  }
  
  class ValueAtRisk extends RiskMetric {
    private confidenceLevel: number;  // α ∈ (0,1)

  }

    compute(lossDistribution: number[]): number;
  }
  
  class CornishFisherVaR {
    // Non-normal adjustment
    adjust(returns: number[]): AdjustedVaR;
  }
  ```
- **Mathematical Formulation:**
  - **Parametric VaR (Normal):**
    ```
    VaR_α = -(μ - z_ασ) · PortfolioValue
    where z_α = Φ^{-1}(α) is the α-quantile of standard normal
    ```
  - **Cornish-Fisher Expansion:**
    ```
    z_α_CF = z_α + (z_α² - 1)·S/6 + (z_α³ - 3z_α)·K/24 - (2z_α³ - 5z_α)·S²/36
    ```
    where `S` = skewness, `K` = excess kurtosis
  - **Historical VaR:**
    ```
    VaR_α = -quantile(losses, α)
    ```
  - **Conditional VaR (Expected Shortfall):**
    ```
    CVaR_α = -E[Loss | Loss > VaR_α] = -1/(1-α) · ∫_α^1 VaR_u du
    ```
  - **Component VaR (Euler Allocation):**
    ```
    CVaR_i = E[Loss_i | Loss > VaR_α]
    ```
- **Tensor Dimensionalities:**
  - Loss distribution: `L ∈ ℝ^M` (M simulated scenarios)
  - Portfolio returns: `R ∈ ℝ^{M×T}` (M paths, T timesteps)
  - Component VaR: `CVaR ∈ ℝ^A` (A assets/modes)

**2. Algorithmic Nuances & Numerical Stability**
- **Cornish-Fisher Implementation:**
  ```typescript
  function cornishFisherAdjust(
    z: number,           // Standard normal quantile
    skewness: number,    // S
    kurtosis: number     // K (excess)
  ): number {
    const z2 = z * z;
    const z3 = z2 * z;
    
    return z +
      (z2 - 1) * skewness / 6 +
      (z3 - 3 * z) * kurtosis / 24 -
      (2 * z3 - 5 * z) * skewness * skewness / 36;
  }
  ```
- **Quantile Estimation:**
  - Use Hyndman-Fan Type 7 (continuous sample quantile)
  - Linear interpolation between order statistics
  - Handle edge cases: `α = 0` or `α = 1`
- **Tail Expectation (CVaR):**
  ```typescript
  function computeCVaR(losses: number[], alpha: number): number {
    const sorted = losses.sort((a, b) => b - a);  // Descending
    const k = Math.floor(alpha * losses.length);
    const tailLosses = sorted.slice(0, k);
    return tailLosses.reduce((a, b) => a + b, 0) / k;
  }
  ```
- **Portfolio Aggregation:**
  - Linear aggregation for VaR (subadditive for CVaR)
  - Marginal VaR: `∂VaR/∂w_i` for risk budgeting

**3. Hardware & Performance Orchestration**
- **Vectorized Quantile Computation:**
  - Use `simple-statistics.quantile()` optimized for sorted arrays
  - Pre-sort losses once, compute multiple quantiles
  - SIMD-accelerated sorting for large arrays
- **Parallel Risk Metrics:**
  ```typescript
  class RiskCalculator {
    async computeAll(losses: number[]): Promise<RiskReport> {
      const [var95, var99, cvar95, cvar99] = await Promise.all([
        this.computeVaR(losses, 0.95),
        this.computeVaR(losses, 0.99),

    }
  }
  ```
- **Memory-Efficient CVaR:**
  - Use selection algorithm (QuickSelect) for top-k losses
  - O(n) average time vs O(n log n) for full sort

**4. Rigorous Testing & Validation Protocol**
- **Kupiec's Proportion of Failures Test:**
  ```typescript
  function kupiecTest(actualLosses: number[], varEstimate: number, alpha: number): TestResult {
    const n = actualLosses.length;
    const failures = actualLosses.filter(l => l > varEstimate).length;
    const p = failures / n;
    
    // Likelihood ratio test
    const LR = -2 * Math.log(
      Math.pow(1 - alpha, n - failures) * Math.pow(alpha, failures) /
      Math.pow(1 - p, n - failures) * Math.pow(p, failures)
    );
    
    // Chi-square(1) critical value
    const criticalValue = 3.841;  // α = 0.05
    const pValue = 1 - chi2.cdf(LR, 1);
    
    return {
      passes: LR < criticalValue,
      pValue,
      failureRate: p,
      expectedRate: alpha
    };
  }
  ```
- **Backtesting Framework:**
  - Unconditional coverage (Kupiec)
  - Independence test (Christoffersen)
  - Conditional coverage (combines both)
- **VaR Accuracy Tests:**
  - Basel traffic light test (green/yellow/red zones)
  - Quantile loss function (pinball loss)
- **CVaR Coherence Check:**
  - Verify CVaR_α ≥ VaR_α (always true by definition)
  - Test subadditivity: CVaR(X+Y) ≤ CVaR(X) + CVaR(Y)

    const n = corrMatrix.rows;
    const result = corrMatrix.clone();
    for (let i = 0; i < n; i++) {

    private failures = 0;

      if (this.state === 'open') {
        throw new Error('Circuit breaker open');
      }
      
      try {
        const result = await fn();
        this.onSuccess();
        return result;
      } catch (error) {
        this.onFailure();
        throw error;
      }
    }
    
    private onFailure() {
      this.failures++;
      if (this.failures > 5) {
        this.state = 'open';
        setTimeout(() => this.state = 'half-open', 60000);
      }
    }

## APPENDIX: MATHEMATICAL REFERENCES

### Key Formulas

1. **Geometric Brownian Motion:**
   ```
   S_t = S_0 · exp((μ - σ²/2)t + σW_t)
   ```

2. **Cholesky Decomposition:**
   ```
   Σ = L · L^T, where L is lower triangular
   ```

3. **Parametric VaR:**
   ```
   VaR_α = -(μ - z_ασ) · V
   ```

4. **Cornish-Fisher:**
   ```
   z_CF = z + (z²-1)S/6 + (z³-3z)K/24 - (2z³-5z)S²/36
   ```

5. **Conditional VaR:**
   ```
   CVaR_α = -E[Loss | Loss > VaR_α]
   ```
